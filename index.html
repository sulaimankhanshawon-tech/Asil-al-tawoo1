Deploying on GitHub & GitHub Pages

How this repository is organized for both GitHub Pages hosting and automated Android CI builds.

1

Push Repository from AI Studio

Use Settings → Push to GitHub in AI Studio. Sensitive files (.env, release keystores, and compiled APKs/AABs) are excluded automatically via .gitignore.

2

Enable GitHub Pages for This Landing Page

In your GitHub repository, open Settings → Pages → Source: Deploy from a branch → Select branch main and folder / (root). GitHub Pages will publish this index.html automatically.

3

Automated Android CI Workflow

Every push to main/master triggers .github/workflows/android-ci.yml to run Robolectric unit tests and assemble a debug APK artifact without exposing private API keys.

Security Reminder: Never commit .env, upload keystores (*.jks), or live API keys into GitHub or public APK releases. Configure GOOGLE_MAPS_API_KEY in the AI Studio Secrets panel or private GitHub Repository Secrets for authorized builds only.
